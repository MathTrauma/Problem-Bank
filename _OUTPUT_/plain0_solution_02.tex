$\triangle\mathrm{ABC}$에서 $\overline{\mathrm{AB}} = \overline{\mathrm{AC}}$이므로

$\angle\mathrm{ABC} = \angle\mathrm{C} = \dfrac{1}{2}\times (180^\circ - 48^\circ) = 66^\circ$

$\therefore \angle\mathrm{DBC} = \dfrac{1}{2}\angle\mathrm{ABC} = \dfrac{1}{2}\times 66^\circ = 33^\circ$

따라서 $\triangle\mathrm{BCD}$에서

$\angle\mathrm{BDC} = 180^\circ - (33^\circ + 66^\circ) = 81^\circ$
