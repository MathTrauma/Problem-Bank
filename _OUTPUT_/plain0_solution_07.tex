$\triangle\mathrm{OAB}$에서

$\angle\mathrm{OBA} = \angle\mathrm{OAB} = \dfrac{1}{2}\times (180^\circ - 40^\circ) = 70^\circ$

$\triangle\mathrm{OBC}$에서

$\angle\mathrm{OBC} = \angle\mathrm{OCB} = \dfrac{1}{2}\times (180^\circ - 50^\circ) = 65^\circ$

$\therefore \angle\mathrm{ABC} = \angle\mathrm{OBA} + \angle\mathrm{OBC} = 70^\circ + 65^\circ = 135^\circ$
