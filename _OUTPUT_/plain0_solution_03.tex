$\overline{\mathrm{AB}} = \overline{\mathrm{AC}}$이므로 $\angle\mathrm{ACB} = \angle\mathrm{ABC} = \angle x$

$\triangle\mathrm{ABC}$에서 $\angle\mathrm{DAC} = \angle x + \angle x = 2\angle x$

$\triangle\mathrm{DAC}$에서 $\overline{\mathrm{AC}} = \overline{\mathrm{CD}}$이므로

$\angle\mathrm{ADC} = \angle\mathrm{DAC} = 2\angle x$

$\triangle\mathrm{DBC}$에서 $\angle\mathrm{DCE} = \angle x + 2\angle x = 3\angle x$

$\triangle\mathrm{DCE}$에서 $\overline{\mathrm{DC}} = \overline{\mathrm{DE}}$이므로

$\angle\mathrm{DEC} = \angle\mathrm{DCE} = 3\angle x$

$\triangle\mathrm{DBE}$에서 $\angle\mathrm{FDE} = \angle x + 3\angle x = 80^\circ$ 이므로

$4\angle x = 80^\circ$ $\therefore \angle x = 20^\circ$
