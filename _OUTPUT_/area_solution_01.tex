위의 그림과 같이 $\overline{\mathrm{AH}}$, $\overline{\mathrm{AC}}$, $\overline{\mathrm{BH}}$, $\overline{\mathrm{EC}}$를 그으면

$\triangle\mathrm{ABC} = 3\triangle\mathrm{AHC}$, $\triangle\mathrm{CDA} = 3\triangle\mathrm{CEA}$

$\therefore \square\mathrm{ABCD} = \triangle\mathrm{ABC} + \triangle\mathrm{CDA}$

$= 3\triangle\mathrm{AHC} + 3\triangle\mathrm{CEA}$

$= 3(\triangle\mathrm{AHC} + \triangle\mathrm{CEA})$

$= 3\square\mathrm{AHCE}$ $\cdots\cdots\mbox{㉠}$

이때 $\triangle\mathrm{EHC} = \triangle\mathrm{EGH}$, $\triangle\mathrm{HEA} = \triangle\mathrm{HFE}$이므로

$\square\mathrm{AHCE} = \triangle\mathrm{EHC} + \triangle\mathrm{HEA}$

$= \triangle\mathrm{EGH} + \triangle\mathrm{HFE}$

$= \square\mathrm{EGHF}$ $\cdots\cdots\mbox{㉡}$

㉠, ㉡에서 $\square\mathrm{ABCD} = 3\square\mathrm{EGHF}$이므로

$\square\mathrm{EGHF} = \dfrac{1}{3}\square\mathrm{ABCD}$ $\therefore k = \dfrac{1}{3}$
