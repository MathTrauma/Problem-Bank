점 $\mathrm{I}$가 $\triangle\mathrm{ABC}$의 내심이므로

$\angle\mathrm{BIC} = 90^\circ + \dfrac{1}{2}\angle\mathrm{A} = 90^\circ + \dfrac{1}{2}\times 50^\circ = 115^\circ$

위의 그림과 같이

$\angle\mathrm{EBD} = \angle\mathrm{DBC} = \angle a$, $\angle\mathrm{DCE} = \angle\mathrm{ECB} = \angle b$

라 하면 $\triangle\mathrm{IBC}$에서

$\angle a + \angle b + 115^\circ = 180^\circ$ 이므로 $\angle a + \angle b = 65^\circ$

이때 $\triangle\mathrm{BIE}$에서 $\angle x + \angle a = 115^\circ$ 이고,

$\triangle\mathrm{CID}$에서 $\angle y + \angle b = 115^\circ$ 이므로

$\angle x + \angle y + \angle a + \angle b = 230^\circ$

$\angle x + \angle y + 65^\circ = 230^\circ$

$\therefore \angle x + \angle y = 230^\circ - 65^\circ = 165^\circ$
